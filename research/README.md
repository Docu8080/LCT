# Исследование репозиториев ФСП

- [Полная выжимка](FSP_REPOSITORIES_DIGEST.md) — сравнение семи проектов, продуктовые механики, архитектура, ограничения и ссылки на закреплённые версии кода.
- [Список идей](IDEAS_CHECKLIST.md) — основа для планирования собственного решения.
- [Манифест](manifest.json) — URL, коммиты и контрольные суммы исследованных источников.
- [Доказательства](evidence.json) и [покрытие](coverage.json) — сохранённые результаты статического исследования.

Дата исследования: 8 октября 2026 года. Сторонние приложения и их тесты при исследовании не запускались. Числа в авторских отчётах не подтверждают качество реального найма.

Полные `sources/` и `archives/` остались локально и исключены из Git. Пути в JSON описывают исследованные снимки; для доступа к оригиналам используйте репозиторий и SHA коммита из манифеста. Код сторонних команд в приложение LTN не переносился. При исследовании форки и изменения в исходных репозиториях не создавались.
