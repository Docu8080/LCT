# LTN

**ФСП Таланты** — локальный MVP платформы ИТ-вакансий и обратного найма по ТЗ специального трека ФСП. Участник подтверждает категории тестом, компания получает объяснимый подбор и отправляет приглашение. Контакты открываются по отдельному разрешению участника.

Стек: Python 3.11–3.13, FastAPI, SQLite, HTML/CSS/JavaScript. Для запуска не нужны Node.js, сборка фронтенда или отдельный сервер БД.

```sh
cd app
./run.sh
```

При первом запуске скрипт скачает фиксированные зависимости, создаст окружение и локальную БД с вымышленными данными. Откройте [приложение](http://127.0.0.1:8080). Демо-аккаунты, настройки и команды проверки — в [app/README.md](app/README.md).

Код приложения написан самостоятельно. Полные снимки чужих репозиториев, архивы, локальные БД, окружения и пароль доступа к облачным материалам в Git не передаются. Официальные материалы сохранены без изменения содержимого. Слайды **7–11** шаблона обязательны: сохраните их дизайн и структуру.

Это демонстрационный прототип: реальные API ФСП не подключены, реквизиты оператора ещё не заданы. Переключение `FSP_DEMO=0` само по себе не делает приложение готовым к эксплуатации.
