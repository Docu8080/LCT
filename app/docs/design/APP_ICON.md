# Иконка «Таланты / ФСП»

Оригинальный векторный знак: «Т» и наклонная черта из написания бренда. Геометрия построена вручную, без шрифтов, внешних картинок и SVG-скриптов. Кобальтовый фон соответствует основному цвету приложения. Это знак проекта, не официальный логотип Федерации.

## Файлы

- `static/mark.svg` — основной редактируемый источник, сетка 512 × 512.
- `static/favicon.svg` — плоская белая версия для малых размеров.
- `static/icons/icon-{192,512,1024}.png` — растровые экспорты основного знака.
- `static/icons/favicon.ico` — встроенные размеры 16, 32 и 48 px.
- `static/icons/apple-touch-icon.png` — непрозрачный квадрат 180 px; скругление применяет система.
- `static/icons/icon-maskable-512.png` — непрозрачный фон и знак внутри безопасной области системной маски.
- `static/site.webmanifest` — имя и иконки ярлыка приложения.
- `docs/design/app-icon-preview.png` — сравнение размеров на светлом и тёмном фоне.

Иконки подключены в главном HTML и документации API. Основной знак используется в навигации; ссылки ресурсов обновлены для сброса кеша. Манифест описывает ярлык приложения, сервис-воркер не добавлялся.

## Проверка

Визуально просмотрены экспорт 512 px и сравнение 16/32/48/64 px. Проверены XML, отсутствие SVG-скриптов, размеры PNG, полная непрозрачность системных иконок, три размера ICO, существование файлов из манифеста и корректный MIME. Все восемь подключённых ресурсов возвращают HTTP 200 через FastAPI TestClient. Проверки HTML-ссылок и синтаксиса `app.js` прошли. Установка ярлыка на реальные устройства не проверялась.
