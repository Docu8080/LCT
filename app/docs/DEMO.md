# Пятиминутная демонстрация

1. Откройте `http://127.0.0.1:8080`. Войдите кнопкой «Кабинет участника». Покажите паспорт навыков и подтверждённую демо-категорию, затем форму и PDF.
2. Откройте «Приглашения»: компания инициировала разговор с зарплатой 190–260 тыс. рублей. Примите приглашение: отдельно подтвердите открытие контактов.
3. Нажмите «Сменить роль» и откройте кабинет компании. Покажите потребность Python Backend Middle и список кандидатов; контакты принятого участника доступны только этой компании.
4. Нажмите «Почему?»: видно вклад категории, теста, стека, ФСП, зарплаты, формата и актуальности. Кандидаты без ФСП остаются в подборе.
5. Отправьте новое адресное приглашение подтверждённому участнику. Оно появится в разделе приглашений работодателя. Если прежнее приглашение ещё активно, сначала отзовите его: API запрещает два активных приглашения одной пары.
6. Вернитесь в кабинет первого кандидата: в «Приватность» отзовите разрешение. Работодатель снова получит обезличенное представление и PDF без контактов.
7. Войдите как «Новый участник». Выберите специализацию и категорию, начните тест, ответьте на первое задание. Обновите страницу: ответ и таймер восстановятся. Вся попытка оценивается с незаполненными заданиями как неверными; для полного результата нужно ответить на все 15.
8. Вернитесь к первому кандидату и покажите «Задания недели». Отправьте решение; работодатель оценит его по трём критериям, кандидат увидит комментарий.
9. Откройте `/docs`: API, ограничения, запросы и схема доступны без внешних библиотек браузера.

Говорите прямо: реальные данные Федерации и её API отсутствуют; демо-реестр и первичные категории — синтетические. IRT-параметры пока экспертные. Числа в валидации получены на симуляции, а не на людях.

Демо-кнопки создают личный сценарий для браузера. Для смены кабинета используйте «Сменить роль»; для исходного состояния — «Начать заново» с подтверждением. При выходе cookie сценария сохраняется: «Новый участник» относится к той же компании. Другие браузеры не видят ваши личные профили/вакансии и сохраняют свои действия. Общие аккаунты с паролем из README подходят для прежних проверок, но не для параллельной демонстрации.

В «Мой профиль» загрузите текстовый PDF до 2 МБ/10 страниц. Проверьте распознанные поля, примените их к форме, затем сохраните профиль. Импорт не подтверждает категорию и не публикует профиль. Можно использовать собственную выгрузку PDF для проверки навыков/контактов.
