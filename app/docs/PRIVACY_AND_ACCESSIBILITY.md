# Приватность и доступность · 11 октября 2026

Изменения относятся к локальному MVP. Это перечень реализованных механизмов и фактических ограничений, а не заключение о полном юридическом соответствии или сертификации WCAG.

| Пункт | Что сделано |
|---|---|
| 1. Конфиденциальность | `/privacy`: данные, цели, получатели, видимость, хранение, сообщения, возраст и удаление. |
| 2. Условия | `/terms`, отдельное подтверждение при регистрации, версия и дата в базе. |
| 3. Возврат | `/refunds`: сервис бесплатен, платежи и комиссии отсутствуют; будущие платные услуги не принимаются автоматически. |
| 4. Cookie | `/cookies`: `fsp_session` для входа, срок 24 часа; `fsp_cookie_notice` хранит версию ознакомления в localStorage. |
| 5. Баннер | Только информационный баннер необходимых cookie: «Понятно» и «Подробнее», повторное открытие; нет фиктивного «отказа» от необходимых cookie, блокировки страницы или разрешения на трекинг. |
| 6. Согласия в формах | Обработка данных, условия и возраст — три независимых незаполненных checkbox. Контакты, публикация и ФСП — отдельные решения. Сервер отвергает строки и числа вместо важных boolean. |
| 7. Сторонний SDK | Во фронтенде нет аналитических, рекламных, платёжных SDK или отправки профиля в LLM. Серверные библиотеки перечислены на `/licenses`; SDK ради списка не устанавливался. |
| 8. Тёмные паттерны | Нет предварительно отмеченных согласий, скрытой подписки, принудительного трекинга. Новый профиль и ФСП скрыты, настройки можно отозвать; удаление доступно обеим ролям. |
| 9. Скрины комиссий | В активном интерфейсе таких материалов нет. Сервис не принимает оплату и не взимает комиссию. |
| 10. Фейковые отзывы | В активных шаблонах отзывы не обнаружены. Паспорт и приглашение на главной явно названы вымышленными примерами. |
| 11. Неподтверждённые заявления | Убрана «независимая оценка» и обещание точного совпадения. Нет гарантии найма, реальной верификации ФСП или официального одобрения Федерации. |
| 12. Альтернативный текст | Знак имеет название в SVG; у декоративного изображения рядом с названной ссылкой `alt=""`, SVG украшения скрыты от скринридера. Данные паспорта — текст HTML, не картинка. |
| 13. Контраст | Исправлены muted/soft, placeholder, границы полей и фокус на тёмной навигации. Восемь выбранных цветовых пар измерены, результат в `privacy_contrast_results.json`. |
| 14. Клавиатура | Нативные ссылки/кнопки/формы и dialog, skip-link, aria-pressed ролей, фокус после переходов/смены задания, radiogroup, озвучивание сохранения и поиска; Escape закрывает меню и dialog. |
| 15. Реквизиты | `/operator` заполняется только пятью переменными `FSP_OPERATOR_*`. Без предоставленных пользователем сведений показано «не указано»; вымышленная компания не создавалась. Этот пункт требует реальных данных владельца. |
| 16. Возраст | Новая регистрация требует явного подтверждения 18+, сервер проверяет его. Дата рождения не собирается. Это заявление пользователя, не проверка документа. Старым аккаунтам принятие не приписывается. |
| 17. Дети и отписка | Детские аккаунты не предусмотрены; ошибочно введённые данные можно удалить. Рекламной рассылки нет; отдельная кнопка записывает отказ от неё без навязывания подписки. |
| 18. Шрифты | Интерфейс использует системные шрифты устройства. Для PDF добавлен оригинальный DejaVu Sans 2.37 с полной исходной лицензией; Arial больше не нужен. |
| 19. Изображения | SVG, PNG и CSS-иллюстрации созданы специально для проекта; стоковых фотографий и чужих картинок в интерфейсе нет. Происхождение описано в `static/licenses/ASSET-RIGHTS.txt`; реквизиты авторов и права на будущие внешние материалы не выдумывались. |
| 20. Удаление | Кабинет обеих ролей: пароль + session/CSRF, удаление связанных записей рабочей базы. После отзыва согласия — отдельный запрос с email/паролем и same-origin/лимитом попыток. Чужие независимые записи сохраняются. |

## Проверка

24 теста прошли: существующие сценарии, новые согласия и даты, миграции, отсутствие секретов в публичных реквизитах, приватные значения по умолчанию, отказ от рассылок, права на удаление, пароль/CSRF и удаление после деактивации с Origin. Проверки синтаксиса трёх JS прошли. Статическая генерация восьми публичных экранов и формы регистрации проходит; подтверждения обязательны и не отмечены заранее. Отдельно проверено, что маршрут реквизитов не заменяет кабинет компании. Скрипт уведомления проверен на показ, закрытие и повторное открытие при доступном и заблокированном localStorage. Скрипт и лицензии доступны по HTTP 200; публичный API реквизитов возвращает только предусмотренные поля.

Контраст проверялся по выбранным парам исходного CSS. Порог обычного текста — 4,5:1, элементов управления — 3:1; критерии описаны в [WCAG 2.2 W3C](https://www.w3.org/WAI/WCAG22/quickref/). Это не измерение каждого отрисованного состояния и не полный аудит со скринридером. Новые экраны не прошли повторную визуальную проверку из-за ранее отклонённого автоматической проверкой браузерного доступа по лимиту использования.
