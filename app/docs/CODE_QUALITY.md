# Проверка кода и отладка

11 октября 2026. Исходная точка: `0cdcbad9432429a45dfb261414aa18dd7f9b6250` в main. Проверены Python-модули приложения и тестов, JavaScript кабинетов/публичных страниц/API/cookie, CSS, HTML, запуск, Docker Compose и CI. Официальные материалы и лицензии сохранены.

## Что исправлено

- Ошибка автосохранения теперь блокирует и переход через меню. До исправления route менялся на profile и экран теста заменялся, несмотря на несохранённый ответ. Общий render ждёт очередь, сохраняет исходный экран и восстанавливает адрес при ошибке. Закрытие страницы с несохранённым ответом вызывает нативное подтверждение браузера.
- Действующая попытка возобновляется только для той же специализации и грейда. Запрос другой категории возвращает 409 вместо молчаливой выдачи прежнего теста.
- Для неизвестного email вход и повторная отправка кода тоже выполняют проверку пароля с уже существующим фиктивным хешем. Убрана очевидная разница в вычислительной работе этих веток; это не заявление о полной защите от всех временных каналов.
- OpenAPI описывает бинарное тело application/pdf, а локальная страница API показывает тип тела вместо предположения, что все запросы JSON.
- Демо-кнопки скрываются по публичной конфигурации. Для личного демо кнопка очистки использует существующий сброс сценария; не предлагает неизвестный пароль синтетического аккаунта. Синтетические записи согласий явно подписаны.
- Кандидат может сохранить «любой формат работы». Раньше сервер принимал any, но список формы его не содержал. Список форматов вакансии остаётся в рамках её серверной схемы. Ограничение длины телефона в форме совпадает с API.

## Проверки разработчика

Из корня репозитория после установки dev-зависимостей:

```sh
python -m pip install -r app/requirements-dev.txt
python -m ruff check app
python -m ruff format --check app
npx --yes prettier@3.9.10 --check "app/static/*.{js,css,html}" "app/tests/*.mjs"
python -m unittest discover -s app/tests -v
PYTHON=python node app/tests/verify_frontend.mjs
node app/tests/check_save_state.mjs
```

CI выполняет эти проверки. Для аудита работающего демо-стенда: `node app/tests/audit_contrast.mjs`.
